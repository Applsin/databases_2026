# Домашнее задание №2

## Предметная область

Онлайн-курсы (EdTech).

В базе данных используются 7 сущностей:

1. User — пользователи системы.
2. Course — курсы.
3. Lesson — уроки.
4. Enrollment — записи студентов на курсы.
5. Review — отзывы.
6. Lesson_progress — прогресс прохождения уроков.
7. Payment — платежи.

## Новые таблицы

В рамках задания были добавлены две таблицы:

- `lesson_progress` — хранит прогресс пользователя по урокам;
- `payment` — хранит информацию об оплате курса.

Для новых таблиц созданы внешние ключи и индексы.

Связь многие-ко-многим между пользователями и курсами реализована через таблицу `enrollment`.

## Проверка ограничений

Было создано 5 намеренных нарушений ограничений базы данных.

| № | Ограничение | Описание нарушения | Исправление |
|---|---|---|---|
| 1 | CHECK | Указана недопустимая роль пользователя | Использовать `student` или `teacher` |
| 2 | FOREIGN KEY | Указан несуществующий преподаватель | Указать существующий `user_id` |
| 3 | NOT NULL | Не указано имя пользователя | Заполнить поле `name` |
| 4 | UNIQUE | Использован уже существующий email | Использовать уникальный email |
| 5 | PRIMARY KEY | Использован уже существующий `user_id` | Использовать другой идентификатор |

Все ошибки были обработаны с помощью блока `EXCEPTION`, а текст ошибки PostgreSQL получен через `SQLERRM`.
