## Вопрос 5 (анализ). Блокировки DDL

В сессии 1 открыта транзакция: `BEGIN; SELECT * FROM flights LIMIT 1;` (не закрыта). В сессии 2 выполняется `ALTER TABLE flights ADD COLUMN c INT;` и «зависает». Что происходит и как разрешить ситуацию?

- A) Дедлок; нужно перезапустить сервер
- B) ALTER TABLE ждёт AccessExclusiveLock, который конфликтует с AccessShareLock открытой транзакции; завершить транзакцию в сессии 1 (COMMIT/ROLLBACK)
- C) SELECT не берёт блокировок, значит зависание вызвано другой причиной
- D) ALTER TABLE невозможен на таблице с данными
