## Запуск в Git Bash

Из корня репозитория с Docker Desktop соберите окружение курса и запустите отдельный контейнер:

```bash
docker build -t seminar9-jupyter "СУБД_5/семинары/студентам/семинар_8/окружение"
MSYS_NO_PATHCONV=1 docker run -d --name seminar9-hw -p 127.0.0.1:8890:8888 --mount "type=bind,source=$(pwd -W)/ДЗ9-Харитонов-Егор,target=/home/student/work" seminar9-jupyter
docker logs -f seminar9-hw
```

Когда Jupyter запустится, завершите просмотр журнала через Ctrl+C. Один раз создайте базу:

```bash
docker exec seminar9-hw createdb -h localhost -U postgres seminar9_hw_1125
```

Откройте http://localhost:8890, введите пароль `student`, выберите `seminar9_completed.ipynb` и выполните Restart Kernel and Run All Cells. Ячейки пересоздают учебные таблицы в базе `seminar9_hw_1125`. Для просмотра сохранённых результатов достаточно открыть ноутбук на GitHub.
