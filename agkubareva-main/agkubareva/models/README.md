# Правило или модель

В ПР № 7 правило темы либо пишут обычным `if` в коде, либо считают моделью scikit-learn. В обоих случаях здесь заполняют:

- название правила и его версия (`rule_version`), например `seller-stock-1`;
- какие колонки файла нужны правилу и в каком порядке;
- где в коде лежат пороги и версия (одно место, не копии внутри функций);
- если модель: какой файл создаётся локально, какой командой он собирается из `data/`; большие файлы весов в Git не кладут.

Профиль `sii` дополнительно пишет, при каких данных правило отказывает (`accepted: false`), а не возвращает число.

Если модель не используется, так и пишут: «модель не используется, правило называется ..., версия ...».
