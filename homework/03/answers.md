### Домашнее задание (Семинар 3): Базовый SQL, DDL/Блокировки и Edge Cases

#### Q1 (Уникальные рейсы и сортировка)

1. Итоговый набор данных у `DISTINCT` и `GROUP BY` одинаковый - уникальные `flight_no`. Различаются только физические
   планы (`Unique`). `ASC` - режим сортировки по умолчанию, писать явно не нужно.
2. Регистр зависит от локали: при `C` заглавные идут раньше строчных, при других локалях - может игнорироваться.

#### Q2 (Аэропорты и выручка за билеты)

1. `SUM(amount)` корректно суммирует оба билета одного пассажира - это выручка. Но `COUNT(*)` посчитает билеты, а не
   пассажиров; для уникальных пассажиров - `COUNT(DISTINCT passenger_id)`.
2. Рейс без билетов `INNER JOIN` отбросит - обязателен `LEFT JOIN`.

#### Q3 (Отмененные рейсы и города)

1. Аэропорт без рейсов должен попасть в результат - из него не было отменённых. Оба варианта (`NOT IN`, `NOT EXISTS`)
   подходят, если нет NULL.
2. Если подзапрос вернёт NULL, `NOT IN` даст пустой результат (условие станет `UNKNOWN`). `NOT EXISTS` этой проблемы
   лишён - он проверяет отсутствие строк, а не сравнивает значения.

#### Q4 (Места на борту и дубликаты)

1. Для уникальных пассажиров - `DISTINCT` или `GROUP BY passenger_id`.
2. Если пассажир сдал билет, но посадочный остался: при JOIN через `ticket_flights` он не попадёт в список, при JOIN
   через `boardings` попадёт.

#### Q5 (DDL и блокировки на живой таблице)

1. `ALTER TABLE ... ADD COLUMN` берёт `ACCESS EXCLUSIVE`, который конфликтует с `ACCESS SHARE` от `SELECT` - DDL будет
   ждать.
2. В PG 11+ `ADD COLUMN ... DEFAULT` мгновенный: значение хранится в `pg_attrdef`, а не в строках; при смене `DEFAULT`
   старые строки останутся со старым значением.
3. `CREATE INDEX` блокирует запись (`SHARE` lock) - для работы без блокировок `CREATE INDEX CONCURRENTLY`, но он дольше
   и может оставить «битый» индекс при сбое.

#### Q6 (Агрегация и NULL в вычислениях)

1. `AVG(actual_departure - scheduled_departure)` игнорирует строки с NULL - среднее считается только по состоявшимся
   рейсам.
2. `COUNT(aircraft_code)` и `COUNT(*)` различаются, если в колонке есть NULL; при `NOT NULL` - одинаковые.
