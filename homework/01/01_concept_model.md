# Задание 1. Концептуальная модель

---

## Основные сущности

1. `User` - клиент сервиса
2. `Restaurant` - ресторан
3. `Courier` - сотрудник доставки
4. `Address` - адрес получателя
5. `Review` - оценка доставки или курьера

## Пример связей между сущностями

- 1:M (один ко многим)
  + Пользователь - несколько заказов
  + Ресторан - разные варианты блюд
  + Курьер - несколько точек (мультизаказ)
- 1:1 (один к одному)
  + Заказ - отзыв
