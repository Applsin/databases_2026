- Студент:

## Повтор, граница, профиль

Правило повтора из строки 7 и какой прямоугольник не должен сработать второй раз.

Строка 9 и фраза «этого в API не будет».

Для prb: кто читает успешный результат. Для sii: где отказываете, вместо того чтобы подставить ноль.
