# ДЗ к семинару 8

Работа с PostgreSQL из Python: psycopg, SQLAlchemy, pandas.

## Как запустить

Из папки `окружение`:

```bash
docker build -t seminar8-jupyter .
docker run -d --name seminar8 -p 8888:8888 seminar8-jupyter
```

Открыть http://localhost:8888 (пароль `student`), загрузить туда `seminar8.ipynb`
и запустить ячейки по порядку.

## Что сделано

1. Поиск по названию через параметр `%s`. Инъекция не срабатывает, запрос возвращает пустой результат.
2. Вставка с повторяющимся `id`. После ошибки откатилась вся транзакция, в таблице 0 строк.
3. Переписал уязвимую функцию: f-строка заменена на параметр.
4. Сравнил цикл и `executemany` на 10 000 строк: `executemany` быстрее примерно в 10 раз.
5. Создал таблицу через SQLAlchemy и вставил 200 строк одним вызовом.
