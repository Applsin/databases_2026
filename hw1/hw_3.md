1 вам нужно вычислить среднюю задержку рейса как avg actual_departure scheduled_departure что произойдет с результатом агрегации если для некоторых рейсов поле actual_departure равно null рейс отменен исключит ли avg эти строки из расчета и как это повлияет на итоговое среднее значение
функция avg полностью игнорирует строки где хотя бы одно из значений равно null. это значит что отмененные рейсы у которых actual_departure пустой не попадут в расчет вообще. в результате среднее значение будет вычислено только по тем рейсам которые действительно состоялись. если таких рейсов не окажется вовсе то результатом будет null. это влияет на итоговое среднее значение так как мы не учитываем отмененные рейсы как нулевую задержку а просто выбрасываем их из статистики

2 в таблице flights есть колонка aircraft_code если вы выполните select count aircraft_code from flights а затем select count from flights будут ли результаты одинаковыми в каком случае они могут различаться и как это связано с ограничением not null на уровне схемы таблицы
результаты будут одинаковыми только если в колонке aircraft_code нет ни одного значения null. функция count с именем колонки считает только непустые значения а count со звездочкой считает все строки подряд. они могут различаться если в таблице есть строки где aircraft_code равен null. если на колонку наложено ограничение not null на уровне схемы то null там появиться не может и значит результаты всегда будут совпадать
